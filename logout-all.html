Komplett abmelden

Achtung: Dies meldet dich von allen Spacenations Tools ab und löscht alle lokal gespeicherten Daten.

Aktuell angemeldet

Was beim Abmelden passiert

  1. Firebase-Auth-Sitzung wird beendet
  2. Alle lokalen Speicherdaten werden gelöscht
  3. Session Storage wird geleert
  4. Local Storage wird geleert
  5. Cookies werden entfernt
  6. Automatische Weiterleitung zur Startseite

Hinweis: Falls es Probleme gibt, hilft außerdem:

  • Browser komplett schließen und neu öffnen
  • Inkognito-/Privat-Modus verwenden
  • Browser-Daten manuell löschen
